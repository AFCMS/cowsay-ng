[cowsay-org/cowsay](https://github.com/cowsay-org/cowsay/tree/af5d2334ce8c594071041e15cba77e674023c082) at commit `af5d2334ce8c594071041e15cba77e674023c082`.

root. Pass a commit, tag, or branch as an argument to select a specific revision:
